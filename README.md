# 파이썬 코딩 연습장 (PyJudge)

학교 수업용 파이썬 온라인 저지입니다. 학생은 학번으로 로그인해 **개념 학습 → 개념 퀴즈 → 코딩 문제** 순서로 공부하고, 제출한 코드는 격리된 채점 컨테이너에서 자동 채점됩니다. 생성형 AI(Gemini, Claude, GPT 중 선택)가 질문 응답과 오답 힌트를 제공합니다.

## 주요 기능

### 학생
- 학번·비밀번호 로그인, 첫 로그인 시 비밀번호 변경
- 문제마다 3단계 학습: 개념 설명 → 퀴즈(객관식/단답형) → 코딩
- 코드 편집기(문법 강조, 자동 들여쓰기), 직접 입력값을 넣어 실행해 보기
- 채점 결과: 정답/오답/시간 초과/메모리 초과/런타임 에러/문법 오류, **케이스별 입력·기대 출력·내 출력·오류 메시지 비교**
- AI 도우미: 자유 질문, 퀴즈 오답 이유 설명, 제출 오답 힌트 (기본 설정에서는 정답 코드를 알려주지 않음)
- 학습 현황: 단원별 진도, 제출 기록, 이어서 풀 문제 안내

### 관리자(교사)
- 대시보드: 학생 수, 오늘 제출·정답률, 14일 제출 추이, 결과 분포, 어려워하는 문제, 상위 학생, 최근 제출
- 학생 관리: 학번·이름 등록(1명 / 여러 명 붙여넣기 / CSV), 비밀번호 초기화, 로그인 차단, 학생별 상세 현황, 진도 CSV 내려받기
- 문제 관리: 문제·개념·퀴즈·테스트 케이스 편집, 공개/비공개, 모범 답안으로 케이스 검증, 재채점, JSON 가져오기/내보내기, 단원 관리
- 제출 기록 조회(학생·문제·결과별), 코드 열람, 재채점
- 통계: 학생×단원 진도표, 문제별 해결률·퀴즈 정답률
- AI 설정: 제공 회사 선택, API 키(암호화 저장), 모델명, 하루 질문 수 제한, 정답 코드 허용 여부, 교사 추가 지침, 질문 기록
- 사이트 설정: 공지, 초기 비밀번호, 퀴즈 통과 후 제출 강제, 비공개 케이스 공개 여부

### 기본 문제
파이썬 기초 **14개 단원, 118문제** (1001~1118번)가 기본 탑재되어 있습니다. 모든 문제에 개념 설명, 퀴즈, 해설, 모범 답안, 채점 케이스가 들어 있습니다.

| 단원 | 문제 수 | 단원 | 문제 수 |
|---|---|---|---|
| 출력: print() | 8 | 중첩 반복과 패턴 | 7 |
| 입력과 자료형 | 9 | 리스트 | 12 |
| 산술 연산 | 10 | 문자열 | 10 |
| 비교·논리 연산 | 6 | 함수 | 6 |
| 조건문 | 12 | 2차원 리스트 | 5 |
| 반복문 for | 12 | 딕셔너리와 집합 | 5 |
| 반복문 while과 반복 제어 | 8 | 종합 응용 | 8 |

## 빠른 시작 (Docker)

```bash
git clone <저장소 주소> pyjudge
cd pyjudge
./setup.sh                    # .env 생성 (관리자 비밀번호, 비밀 키)
docker compose up -d --build  # 실행
```
브라우저에서 `http://서버주소:8000` 에 접속해 관리자 계정으로 로그인합니다.

서버 준비, 도메인·HTTPS, 백업, 업데이트 방법은 [docs/배포가이드.md](docs/배포가이드.md), 수업 운영 방법은 [docs/사용가이드.md](docs/사용가이드.md)를 참고하세요.

## 구조

```
app/              웹 서버 (Flask)
  student.py      학생 화면·채점·AI API
  admin.py        관리자 화면
  ai.py           Gemini / Claude / OpenAI 연동
  judge_client.py 채점 요청 큐
judge/            채점기 (웹 서버와 분리된 컨테이너에서 실행)
  runner.py       자원 제한·권한 축소·위험 기능 차단 후 코드 실행
  server.py       채점 HTTP 서버
problems/         기본 문제 JSON
tools/            문제 원본과 빌드 스크립트
tests/            자동 점검 테스트
docker-compose.yml, Dockerfile, Dockerfile.judge
```

## 채점 보안

학생 코드는 웹 서버가 아닌 별도의 `judge` 컨테이너에서 실행됩니다.

- 인터넷과 차단된 내부 네트워크, 읽기 전용 파일 시스템, 프로세스 수·메모리·CPU 제한
- 학생 코드는 권한 없는 사용자(nobody)로 실행되며 실행 시간·메모리·출력 크기 제한
- 네트워크 소켓, 외부 프로그램 실행, ctypes 사용 차단
- 데이터베이스와 API 키는 채점 컨테이너에 존재하지 않음

## 개발 환경에서 실행 (Docker 없이)

```bash
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
flask --app wsgi run --debug        # http://127.0.0.1:5000, 초기 관리자 admin / admin1234
python tests/test_smoke.py          # 기능 점검
```
이 방식은 채점이 웹 서버 안에서 실행되므로 개발·시험용으로만 사용하세요.

## 문제 추가·수정

- 관리자 화면에서 직접 편집하거나 JSON 파일로 가져옵니다.
- 기본 문제 원본은 `tools/problems_a.py`, `tools/problems_b.py`에 있으며, 수정 후 `python tools/build_problems.py`를 실행하면 모범 답안으로 정답을 다시 만들어 `problems/python_basic.json`을 갱신합니다.
